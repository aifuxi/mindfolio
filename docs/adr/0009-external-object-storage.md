# 使用外部对象存储保存文件

管理者选择将文件接入外部 S3 兼容对象存储，预期使用阿里云 OSS，使文件持久化独立于应用所在 VPS。PostgreSQL 保存文件元信息和对象标识，文件内容保存在对象存储；OSS 的具体 SDK 与配置需根据其 S3 兼容范围进行验证。区域与 Bucket 尚待确定，接入约定与参考资料见[技术方案](../../.scratch/technical-plan/spec.md)。

文章图片随文章权限变化，草稿图片私有，文章撤回后拒绝通过该文章发起的新的公开图片访问。因此对象存储保持私有，图片通过 Rust 媒体接口逐请求校验后流式返回，避免下载直链或缓存绕过撤回状态；这会增加 VPS 的图片读取流量。
