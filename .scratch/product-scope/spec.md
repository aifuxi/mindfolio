# 个人管理系统功能范围

状态：功能范围已确认

## 目标

帮助唯一的管理者规划并完成项目任务、坚持习惯、记录日常，同时管理公开网站的站点信息、文章和友链。个人管理是首要用途；公开网站在后续阶段交付。

## 使用者与可见范围

- 管理者：唯一可以管理任务、习惯、每日记录、文章和友链的人。
- 访客：仅阅读已经公开的文章和友链。
- 草稿与撤回的文章只对管理者可见。
- 项目、任务、习惯与每日记录属于私人内容。

## 第一阶段：个人管理

### 项目与任务

- 可以创建项目，在项目下创建任务，并将任务拆成一级子任务。子任务有自己的状态和日期，不再继续拆分。
- 临时任务可以先进入收件箱，再归入项目。
- 项目提供待规划区，用于存放尚未进入执行流程的任务。
- 同一项目的任务可以通过看板或列表查看。
- 任务具有标题、说明、状态、优先级、计划日期、截止日期和任务标签；日期、优先级、任务标签可按需填写。
- 任务说明采用 Markdown 编辑与预览。
- 所有项目采用统一状态：待办、进行中、已完成、已取消；待规划区独立于这些状态。
- 可以主动把任务安排在“今日”。“今日”汇总计划当天执行、当天到期和已逾期的未完成任务。
- 父任务由管理者手动完成；仍有未完成子任务时给出提示。
- 保留任务完成历史，以供回顾。
- 删除任务或项目后，日常任务列表移除相关内容，已有完成历史仍在每日汇总与每周回顾中保留。
- 项目可以标记完成、归档和恢复；归档保留项目及任务历史，删除是单独操作。
- 可以按关键词查找任务，并按状态、优先级、日期和任务标签筛选。
- 第一阶段不自动生成重复任务。

### 习惯

- 可以设定每天执行，或每周灵活完成指定天数的习惯。
- 每个日期用“完成／未完成”记录，不要求输入时长或数量；具体情况可写入备注。
- 可以补记过去日期的打卡，也可以暂停习惯；暂停期间不计入完成率，普通漏打卡按未完成处理。
- 展示打卡日历及周、月完成率；不引入复杂评分。

### 每日记录

- 每天可以写一篇简短记录，并可反复修改。
- 每日记录采用 Markdown 编辑与预览。
- 当天完成的任务和习惯打卡在同一天的页面旁边展示，不自动写入记录正文。
- 每日记录与任务完成历史、习惯打卡历史各自保留。

### 今日与每周回顾

- “今日”集中查看待处理任务、待打卡习惯和当天的每日记录。
- “今日”醒目提示待办任务、已逾期任务和未打卡习惯；第一阶段不发送站外通知。
- “每周回顾”集中查看本周已完成任务、习惯执行情况及每日记录。

### 数据导出

- 管理者可以手动导出项目、任务、习惯及打卡历史、每日记录。

## 第二阶段：公开网站

### 网站管理

- 管理者可以在一个地方配置网站名称、副标题、简介、Logo、浏览器图标、作者昵称、作者头像、作者简介和页脚版权文字；联系邮箱可选填。
- 管理者可以配置多条社交链接；每条分别设置链接、展示文案和图标，也可以不配置社交链接。
- 管理者可以编辑首页介绍，以及导航菜单的名称、链接和顺序；文章列表按已发布内容自动展示。
- 管理者可以设置网站在搜索结果和分享卡片中的默认标题、描述与图片。
- 管理者可以选择浅色或深色模式，并配置主题色；页面布局保持固定。
- ICP 备案信息和公安备案信息分别可选填：前者包含备案编号和查询链接，后者包含备案编号、查询链接和备案图标。
- 已配置的备案信息展示在公开网站的页脚，编号可跳转至相应查询入口；未配置的备案信息不显示空占位，也不妨碍保存其他网站设置。
- 网站管理功能在公开网站对访客开放前完成。

### 访问统计

- 网站管理分别提供 Google Analytics 4 和百度统计（站长版）的配置入口；两项都可不填，也可以只启用其中一项或同时启用两项。
- 管理者可以分别启用或关闭已配置的统计服务；统计结果在对应服务的后台查看，本系统不另建统计看板。
- 第一版关注公开页面访问量和文章页阅读量，不额外记录友链、社交链接等点击事件。
- 私人的管理页面不计入公开网站访问统计。

### 文章

- 管理者可以撰写草稿、发布文章、撤回已发布文章。
- 文章图片随文章的公开状态变化：草稿图片仅管理者可见，撤回后拒绝通过该文章发起的新的公开图片访问；已经下载的内容无法收回。
- 每篇文章归入一个分类，可关联多个文章标签。
- 访客可以阅读已发布的文章，并按标题搜索、分类和文章标签浏览。
- 可以手动将写文章的任务与对应文章关联；发布文章不会自动完成任务。
- 站点信息、文章和友链纳入管理者可手动导出的数据范围。
- 暂不加入定时发布、访客评论或订阅。

### 友链

- 管理者手动维护友链。每条友链包含名称和网址，可选填简介与图标。
- 管理者可以调整友链顺序、暂时隐藏或重新展示；访客只能浏览已展示的友链。

## 已确认的范围限制

- 多管理者、访客注册或团队协作。
- 第一阶段不自动生成重复任务，也不发送站外提醒。
- 访客评论、订阅和定时发布文章。
- 复杂的习惯评分机制。
- 除手动关联任务与文章外，不增加习惯、每日记录与其他模块的关联操作。
- 第一版访问统计不包括站内统计看板或额外的点击事件。
- 百度搜索资源平台的收录与搜索表现管理不属于本次访问统计功能。

## 典型使用场景

1. 早上打开“今日”，看到计划今天做、今天到期或已经逾期的任务，以及需要打卡的习惯；把收件箱中的任务归入项目或安排到今天。
2. 工作时在项目看板或列表中推进任务，必要时拆分子任务；晚上打卡习惯、写每日记录，并在同一天看到完成历史。
3. 周末打开“每周回顾”，检查已完成任务、习惯完成率和每日记录；完成的项目可以归档，同时保留历史。
4. 公开网站启用前，管理者填写站点信息；如已取得备案信息，可分别填写并核对访客可见的页脚。撰写文章时，可把草稿与写作任务手动关联。
5. 文章发布后供访客按标题、分类和文章标签查找，友链供访客浏览。
6. 管理者在网站管理中启用外部统计服务，随后前往所选服务的后台了解公开网站和文章的访问情况。
