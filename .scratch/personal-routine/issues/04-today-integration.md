# 将习惯与每日记录接入完整“今日”

Status: ready-for-agent

## 目标

让管理者在现有“今日任务”入口同时处理待办任务、待打卡习惯和当天每日记录。

依据：[本批规格](../spec.md)、[功能范围](../../product-scope/spec.md)、[上一批今日任务](../../project-task/issues/07-today-tasks.md)。

## 实施范围

1. 保留现有今日任务的聚合与安排操作，在同一页面加入今天应执行且未完成的习惯、当天打卡状态和每日记录入口。
2. 按服务端上海业务日期决定今天及应执行习惯；暂停中的习惯不提示打卡。逾期任务、其他待办任务和未打卡习惯有清楚的视觉提示。
3. 页面支持直接完成或更正当天习惯打卡，并进入当天每日记录；相关状态更新后即时刷新，不覆盖未提交的记录正文。
4. 如增加聚合接口，仍使用私人边界和生成契约；保持任务、习惯、每日记录各自数据所有权。
5. 验证上海跨日、暂停、任务去重、空状态及关键页面流程。

## 验收条件

- “今日”正确展示计划当天、当天到期和逾期任务，以及今天应执行的习惯与当天每日记录；暂停习惯不作为待打卡提示。
- 当天打卡或编辑记录后页面状态同步，任务安排与原截止日期语义不变；没有习惯或记录时显示真实空状态。
- 上海跨日的受控时钟测试、私人鉴权、CSRF、浏览器关键流程、契约检查与 `mise run ci` 通过。

## 依赖与交接

- 依赖任务 03，以及上一批 07 的今日任务接口。
- 本任务不发送站外提醒，不自动生成重复任务。
- 验收后记录检查结果，并单独提交。
