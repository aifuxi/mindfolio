# 实现每周回顾

Status: ready-for-agent

## 目标

让管理者按上海业务周回看已完成任务、习惯执行和每日记录。

依据：[本批规格](../spec.md)、[功能范围](../../product-scope/spec.md)、[完成历史 ADR](../../../docs/adr/0010-preserve-task-completion-history.md)。

## 实施范围

1. 提供按周查询的私人回顾 API；周一至周日由服务端按 `Asia/Shanghai` 确定，允许选择过去周与当前周。
2. 汇总该周任务完成记录及其名称快照、各习惯的执行和目标达成情况、每日记录日期与正文。任务或项目已删除时仍展示既有完成记录。
3. 管理端提供周切换、分日浏览和汇总视图，并能跳转仍存在的当前内容；已删除对象只展示历史快照。
4. 分页或限制大结果，保持稳定顺序；周范围查询不扫描无关日期。
5. 更新契约与真实数据库、浏览器测试。

## 验收条件

- 跨上海周界的完成记录、打卡和每日记录进入正确周；当前周不把未来日期算作漏打卡。
- 删除项目或任务后仍能看到既有完成历史；历史名称不随当前名称变化。
- 每周目标、暂停和跨月周与习惯统计口径一致；无数据周有明确空状态。
- 私人鉴权、真实 PostgreSQL HTTP 测试、浏览器回顾流程、契约检查与 `mise run ci` 通过。

## 依赖与交接

- 依赖任务 04，复用上一批 06 的完成记录和任务 02、03 的历史查询。
- 本任务不编辑既有历史，也不创建全量操作审计。
- 验收后记录检查结果，并单独提交。
