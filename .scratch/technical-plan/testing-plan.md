# 技术实施验收边界

状态：已作为工程默认方案纳入实施规格；测试侧重点可根据管理者反馈调整

## 原则

以可观察的业务行为、数据约束与权限边界为验收对象。接口与真实 PostgreSQL 集成测试承担主要业务组合，浏览器只覆盖关键操作链路；不为简单数据转发、内部函数组织或依赖库行为重复编写测试。

## 接口与真实数据库

- 从空数据库执行真实迁移，通过 HTTP 接口验证唯一管理者鉴权、会话撤销与 CSRF。
- 验证项目、任务、一级子任务、今日归集、习惯补记与暂停、每日记录唯一性、每周回顾和导出。
- 覆盖完成记录保留、删除后的历史查询、事务原子性、日期边界与并发更新冲突。
- 第二阶段覆盖公开状态过滤、文章和图片撤回后的访问控制，以及条件请求与 Range 请求不会绕过权限校验。
- 站点与可见友链引用的图片可经对应入口读取，未引用的私有文件不可通过站点媒体入口访问。

## 浏览器关键流程

- 登录后创建并完成任务，重新打开或删除后仍可回顾既有完成记录。
- 编辑、预览并保存 Markdown；危险 HTML 或链接不能执行脚本。
- 补记习惯，保存每日记录，查看今日和每周回顾。
- 第二阶段验证文章发布、访客访问和撤回，并核对 SSR HTML 的正文及公开元信息。

## 契约与构建

- 使用锁定的 mise、Rust、Node.js 和 pnpm 版本重建环境，本地与 CI 经相同 mise 任务执行检查、测试和构建。
- rustfmt 检查 Rust 格式，Clippy 覆盖工作区全部目标；ESLint 覆盖 Vue 与 TypeScript，Prettier 检查格式，Vue 类型检查独立执行。
- 验证格式错误、lint 警告和类型错误使统一检查失败，检查不自动修复源码；第二阶段 Nuxt 的准备步骤先于其 lint 和类型检查。
- 缺少工具、依赖、源码或必要生成产物时不得用空任务、跳过或忽略退出码冒充通过；初始化验收记录实际覆盖范围。
- Rust DTO 生成 OpenAPI 与 TypeScript 类型，检查产物变化与前端类型检查结果；覆盖字符串 ID、日期和错误响应等关键契约。
- 检查空库迁移、支持版本的升级迁移、前后端构建和可追溯镜像发布。
- 第一阶段只验证个人管理实际需要的模块，公开网站相关验收在第二阶段执行。

## 真实环境验收

- 在实际 OSS 测试 Bucket 验证候选 SDK、预签名上传、私有读取、对象保留与浏览器跨域；本地模拟不能替代该项。
- 在目标部署环境验证 GHCR 镜像拉取、Portainer 版本更新、SSH 恢复入口、Caddy 持久化状态恢复、资源占用和健康检查。
- 从服务器外备份在隔离环境完整恢复数据库，并核对关联文件及关键数据；以备份快照时间验证 RPO，以实际恢复用时验证 RTO。

## 当前验证情况

仓库尚无应用代码或既有测试边界。本轮仅整理规格与核对资料，没有运行应用测试、连接实际 OSS 或执行备份恢复。
