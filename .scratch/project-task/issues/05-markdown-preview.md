# 实现任务说明的 Markdown 编辑与安全预览

Status: done

## 目标

让管理者使用 Markdown 编写、保存和预览任务说明，同时确保预览不会执行不可信 HTML 或加载远程图片。

依据：[本批规格](../spec.md)、[功能范围](../../product-scope/spec.md)、[技术实施规格](../../technical-plan/spec.md)。

## 实施范围

1. 在任务 02 保存 Markdown 原文的基础上，提供编辑、预览和再次打开的完整管理端流程；普通列表、链接和代码片段具有一致的显示效果。
2. 配置 Markdown 解析与输出边界：关闭原始 HTML，拒绝危险链接协议和远程图片加载；新窗口链接隔离 opener。服务端继续保存原文，不把浏览器渲染后的 HTML 当作第二份正文。
3. 预览接入已有私人任务详情与版本冲突处理。修改说明时沿用 Session、CSRF 和来源校验；冲突时保留未提交的文本。
4. 对真实保存与重新读取，以及浏览器中的安全行为编写必要测试，接入 `mise run ci`。

## 验收条件

- 管理者可编辑、预览并保存 Markdown 说明；重新打开仍得到原文，正常列表、代码片段和安全链接按预期显示。
- 危险 HTML、脚本链接和远程图片不会在预览中执行或加载；新窗口链接不能访问原页面的 opener。
- 未登录或缺少有效 CSRF、来源错误的修改请求被拒绝；版本冲突返回 409，管理端保留未提交正文。
- 真实 HTTP 与 PostgreSQL 测试、浏览器安全与编辑流程以及 `mise run ci` 通过。

## 依赖与交接

- 依赖任务 04；复用既有任务说明字段，不建立附件上传或富文本编辑器。
- 完成后记录危险输入与正文保留的验收结果，并单独提交。

## 验收记录

- 2026-09-27：管理端任务创建与编辑表单增加即时 Markdown 预览。使用锁定的 `markdown-it` 解析普通列表、链接和代码片段，再将允许的 token 渲染为 Vue 节点；不插入解析器生成的 HTML。服务端继续只保存说明原文，没有增加第二份正文。
- 解析器禁用原始 HTML；渲染层仅使用允许的结构标签并再次校验链接协议，只允许 HTTP、HTTPS、邮件及安全相对链接。图片语法仅显示替代文字，不创建图片元素；新窗口链接设置 `noopener noreferrer`。
- 真实 PostgreSQL HTTP 测试确认 Markdown 原文创建、修改和重新读取一致，未登录读取、错误 CSRF 与来源被拒绝，旧版本写入返回 409 且不覆盖已保存正文。Chromium 流程确认列表与代码显示、保存后再次打开、冲突时保留未提交文字；危险 HTML、脚本和 `data:` 链接不执行，远程图片无请求，新窗口的 `opener` 为空。
- `mise run ci` 通过：格式、Clippy、ESLint、Vue 类型、契约漂移、空库与重复迁移、真实 PostgreSQL HTTP 测试、Chromium 浏览器测试和构建。
