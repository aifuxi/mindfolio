# 实现收件箱与项目任务基础操作

Status: done

## 目标

让管理者把任务先放进收件箱或直接归入项目，维护任务的基本字段，并安全记录首次及后续的完成事实。

依据：[本批规格](../spec.md)、[功能范围](../../product-scope/spec.md)、[契约约定](../../technical-plan/spec.md)、[完成历史 ADR](../../../docs/adr/0010-preserve-task-completion-history.md)。

## 实施范围

1. 通过版本化迁移建立任务与任务完成记录的基础结构。任务可没有项目而位于收件箱；计划日期、截止日期、优先级可为空，说明保存 Markdown 原文。完成记录与任务当前状态分开存储，保存必要名称快照与完成时刻。
2. 实现任务创建、列表、详情、编辑、从收件箱归入项目及在项目之间移动的私人 API。项目任务的待规划区信息与待办、进行中、已完成、已取消四种状态分别表达。
3. 实现状态变更：从非完成状态进入已完成时在同一事务内追加一条完成记录；重复提交不产生重复完成事实；重新打开不删除旧记录，之后再次完成可追加新的事实。删除和历史查询在任务 06 完成。
4. 管理端提供收件箱与项目任务的基础列表和编辑流程，可输入标题、说明、状态、优先级、计划日期、截止日期及待规划区信息；标签和看板留给任务 04，Markdown 预览留给任务 05。
5. 沿用任务 01 的服务端私人访问边界和乐观并发校验；生成 OpenAPI 与 TypeScript 类型。

## 验收条件

- 未登录、错误 CSRF 或错误来源不能读取或修改任务。收件箱任务无项目；移动到项目后从收件箱退出，项目任务可进入或离开独立的待规划区。
- 四种状态与可选字段可正确保存、清空和读取；资源 ID 是字符串，业务日期按 `YYYY-MM-DD` 传输，空值与字段缺省语义明确。
- 完成、重复完成、重新打开后再次完成分别产生 1、0、1 条新增完成记录；状态与记录写入在事务中保持一致。版本冲突返回 409 且页面保留输入。
- 真实 PostgreSQL HTTP 测试、必要浏览器流程、契约漂移检查和 `mise run ci` 通过。

## 依赖与交接

- 依赖任务 01。
- 本任务不实现子任务、标签、搜索、看板、删除或完成历史页面。完成记录结构须支持任务 03 的子任务和任务 06 的删除后保留。
- 完成后记录实际迁移、状态边界和重试验收结果，并单独提交。

## 验收记录

- 2026-09-27：新增 `202609270003_tasks.sql`，建立任务与独立的任务完成记录。任务使用 `BIGINT IDENTITY`，项目归属可为空；数据库约束限定四种状态、可选优先级、标题、版本及“收件箱不能进入待规划区”。完成记录保存任务 ID、标题、项目名称快照和完成时刻，不设置会在删除任务时级联清理记录的外键。
- 私人 `/tasks` API 提供创建、按收件箱或项目分页列出、详情与版本化编辑。可从收件箱归入项目、在项目之间移动，也可移回收件箱；待规划区与任务状态分别保存。业务日期以 `YYYY-MM-DD` 字符串传输和 PostgreSQL `DATE` 保存。更新时缺省字段保持原值，可空字段传 `null` 清空；移回收件箱且未显式指定待规划区时自动退出待规划区。
- 任务从非完成状态进入已完成时，在同一事务中更新状态并写入完成记录；相同版本下重复设置已完成不增加记录，旧版本重试返回 409 且不增加记录；重新打开后再次完成会增加一条。创建时直接指定已完成也写入一条完成记录。
- 管理端提供收件箱及项目任务列表、创建和编辑入口，可维护标题、Markdown 原文说明、状态、优先级、计划日期、截止日期及待规划区。版本冲突时保留表单输入，取得最新版本后可继续编辑；标签、看板、Markdown 预览和完成历史页面仍归后续 issue。
- macOS arm64 上 `mise run ci` 完整通过：格式、Clippy、ESLint、Vue 类型、OpenAPI 契约、空库与重复迁移、真实 PostgreSQL HTTP 测试、Chromium 浏览器测试和构建。任务集成测试验证权限与来源、字段保存和清空、收件箱及跨项目移动、四种状态、完成重试、名称快照、版本冲突，以及完成记录写入失败时任务状态回滚。浏览器测试覆盖创建、归入项目、待规划区、完成和冲突后保留编辑；已检查任务页实际截图并修正日期控件布局。

## 遗留问题与下一步

- 本任务未实现子任务、标签、搜索、看板、删除或完成历史页面。03“一级子任务”需在现有任务结构上增加一级父子关系，沿用私人访问边界、版本校验和完成记录事务。
- 本次完成的是本地 CI；尚未验证本次提交的远端 GitHub Actions 运行。03 issue 在本任务提交后再更新状态并开始实施。
